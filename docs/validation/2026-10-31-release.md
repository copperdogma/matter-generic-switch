# Release validation — 2026-10-31

## Final result

Application **2.1.1**, ESP-IDF **6.0.2**, managed ESP-Matter **1.6.1**, button component **4.2.3**. The connected ESP32-C3 is running the application-only, hash-verified maintenance image. Pairing and network state were retained.

## Checks

- Existing board-profile build: passed without compiler warnings/errors.
- Fresh configuration generated from tracked defaults and component lock: full C3 build passed without compiler warnings/errors. Checked 22 critical identity, partition, transport and version settings against the board profile; all matched. These are not byte-identical build profiles: fresh defaults select size optimization, while the retained board profile has historical configuration choices.
- Native regression: `tests/run_led_indicator_test.sh` passed, compiling the actual LED driver against deterministic timer/LEDC fakes. Covers repeat sequences, interrupted restart, three completed pulses, explicit cancellation, final off and timer termination. The test fails against the pre-fix driver. It does not measure physical GPIO timing.
- Unused diagnostic TestEventTrigger is disabled in both generated configurations; its enable key is absent. The existing development/example commissioning identity was intentionally preserved.
- Before flash: USB identity checked against the intended device; generated partition table matched the private full-device backup byte-for-byte; image fit the existing OTA slot; app-flash arguments contained only 0x20000 and the application binary.
- Flash: esptool verified the written application hash. Bootloader, partition table, OTA metadata, NVS, keys and factory partitions were not written.
- Final 70-second serial capture: 2.1.1 and the expected ELF hash; momentary endpoint ready; both fabrics and original commissioning codes restored; IPv4 acquired around 12 seconds; later RSSI -64 dBm; no post-boot reset or Wi-Fi disconnect.
- One subscription-resumption timeout remained in the capture. No new end-to-end Home/physical-LED acceptance is claimed for 2.1.1. The unchanged momentary lamp-toggle logic was owner-accepted in both directions on 2.1.0; 2.1.1 changes LED feedback and diagnostic-test availability only.
- Public-push review: device identifiers, private network addresses, household labels, raw logs and recovery images are excluded. Local documentation links and Git whitespace checks passed.
